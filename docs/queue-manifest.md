# Queue Manifest（P0 最短可运行闭环优先）

## 说明
- 本清单用于把「一 CE = 一 issue」排成可执行队列：先保证最短可运行闭环，再补齐验收必需依赖。
- 仅描述入队顺序、依赖与并行波次；不包含实现细节。
- 分段遵循：Stage A（基础骨架）→ Stage B（核心交互）→ Stage C（预览与性能）。

## Stage A — 基础编辑闭环（可打开/可渲染/可选择/可拖入/可移动/可改属性）

### 入队顺序（线性主线）
1. CE-001 初始化工程与目录（无依赖）
2. CE-002 编辑器 App Shell 五区布局（依赖：CE-001）
3. CE-004 定义核心类型与 DTO（依赖：CE-001）
4. CE-005 实现 nodes / childrenMap 与转换层（依赖：CE-004）
5. CE-006 落地 EditorStore 六层结构（依赖：CE-004）
6. CE-009 Registry 注册协议与查询 API（依赖：CE-004）
7. CE-010 UnknownComponent 兜底（依赖：CE-009）
8. CE-011 注册 MVP 内置组件（依赖：CE-009）
9. CE-013 DOM Renderer 递归渲染（依赖：CE-005, CE-009）
10. CE-014 Overlay Layer 基础能力（依赖：CE-013）
11. CE-015 Palette / Layers / Inspector 接线（依赖：CE-002, CE-006, CE-013）
12. CE-017 选择系统（依赖：CE-014, CE-015）
13. CE-018 从组件库拖入（依赖：CE-011, CE-014, CE-017）
14. CE-019 画布内移动与复制拖拽（依赖：CE-017, CE-018）
15. CE-026 Inspector Local Draft State（依赖：CE-015, CE-017）

### 并行波次（可并行启动建议）
- wave-1：CE-002 与 CE-004（前置：CE-001）
- wave-2：CE-005、CE-006、CE-009（前置：CE-004）
- wave-3：CE-010 与 CE-011（前置：CE-009）
- wave-5：CE-014 与 CE-015（前置：CE-013；且 CE-015 额外依赖 CE-002、CE-006）
- wave-8：CE-019 与 CE-026（前置：分别满足依赖即可）
